# PR and issue text is Ibrahem's

Settled 2026-11-05 at init from upstream `CONTRIBUTING.rst` ("AI-Assisted Contributions").

Upstream accepts reviewed AI-assisted code but asks that issues, PR descriptions and review
replies be written by the contributor. The agent offers the facts (what broke, the test,
the fix) as bullets; Ibrahem writes the text. Grammar cleanup of Ibrahem's own draft is allowed.
Rejected: the global default of drafting PR descriptions in Ibrahem's voice; the project rule wins.
